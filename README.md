# sensor_performance_estimation

Acquisition planning, synthetic sample data, and analysis code for the
**VSX3000 Resolution, Area-Fidelity, Detectability, and Noise Characterization
Procedure**, together with the technician-facing step-by-step procedure for the
sensor performance test.

- `docs/procedures/performance_test_procedure.md` (and `.docx`) is the
  procedure: equipment, targets, setup, registration, the five capture series,
  data logging, checks, and how to run the analyses. It is generated by
  `docs/procedures/build/build.py` from a template, so every count it quotes
  comes from `sensorperf/parameters.py` and the planner, and the build gate
  (`docs/procedures/build/verify_doc.py`, with `Review/manifest.json`) checks
  that the figures, tables and prose agree.
- `docs/design/code_design.md` is the module and interface contract.
- `sensorperf/` is the Python package:
  - `parameters.py`: every named constant of the procedure (Section 2) and the
    relations p(Z), theta, D_px, k = f_x B, delta Z_q.
  - `acquisition/`, `cli/plan_stations.py`, `cli/make_manifest.py`,
    `cli/check_captures.py`, `cli/register.py`: Part I tools (plan with logged
    randomization, manifest from the robot's pose log, quick-look check with the
    D pilot post check, robot-to-sensor registration by plane correspondence).
  - `analysis/`, `cli/analyze.py`: Part II analyses A (noise), B (resolution in
    H, V and Z), C (area fidelity), D (detectability), E (boundary bias), and
    the `forward_model_parameters.json` hand-off.
  - `simulate/`, `cli/simulate.py`: an indicative VSX3000-like renderer of the
    two-plane targets that writes a complete synthetic session (sample data)
    so every tool and analysis can be run without the sensor.
  - `io/`, `geometry/`, `features/`, `stats/`: shared code; the `.mc` reader,
    the pinhole camera and rigid transforms are reused from the
    `depth_calibration_from_spherical_target` repository.

## Quick start

```
pip install -e ".[figures,test,docs]"      # or: pip install -r requirements.txt
python3 -m pytest -q
python3 -m sensorperf.cli.simulate --out data/synthetic_quick --quick
python3 -m sensorperf.cli.check_captures --session data/synthetic_quick
python3 -m sensorperf.cli.analyze --session data/synthetic_quick
python3 docs/procedures/build/build.py   # rebuild the procedure document
```

The analyses write `analysis/` inside the session folder: one CSV summary and
one JSON detail file per analysis, figures as PNG and SVG, and
`forward_model_parameters.json`.

## Conventions

Camera frame: the left IR camera, Z along the optical axis, H along image
columns, V along image rows. Target frame: origin at the front-face center, z
pointing away from the sensor, back plate at z = +G. Depth is camera z in
millimeters; a no-read is NaN inside the package. See the design document.
